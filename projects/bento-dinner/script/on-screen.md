# 畫面建議（給分鏡參考）

- **開頭大字：** 便當飯多菜少　晚餐怎麼吃？
- 「飯很多、菜很少、蛋白質不夠」→ 會議便當俯視圖，飯區很大、菜和肉很小，三個區塊依序標出來
- 「晚上很餓卻不敢吃」→ 時鐘從 12:00 轉到 19:00，空盤子
- 「一整天當成一個餐盤」→ 中午便當＋晚餐盤合成一個大餐盤
- 「豆魚蛋肉一個掌心大」→ 手掌圖示疊在一塊魚／豆腐上（標出處：國健署「我的餐盤」）
- 「中午缺的，晚餐補回來」→ 便當缺的格子（菜、蛋白質）移到晚餐盤
- 晚餐三樣依序出現：🥗 一份蔬菜 → ✋ 一掌心蛋白質 → 🥜 一茶匙堅果
- 「體態管理，從來不是靠挨餓」→ 大字收尾
- CTA：留言「體態管理」　領 7 天減脂懶人包
- 不畫：產品、體重計數字、前後對比
