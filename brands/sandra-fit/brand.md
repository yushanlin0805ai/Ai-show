# brand.md：宇姍教練

## 配色（覆蓋 design-system.md 的 token）

> 使用者指定：底色奶茶色（淺底深字）、強調色玫瑰紅（不要綠色字）。2026-11 第一支影片定案。

| Token | 色碼 | 用途 |
|---|---|---|
| `--bg` | `#E9D8C2` | 奶茶色底；也用作深色塊上的文字 |
| `--ink` | `#3B2F27` | 主要文字（深咖啡）；膠囊標籤、數字徽章的底色 |
| `--r1` | `#8A5A44` | 咖啡：次要分類 |
| `--r2` | `#A07D38` | 暖金：次要強調 |
| `--r3` | `#C9566A` | 玫瑰紅：**本集主角**、重點字、光圈外框 |
| `--r4` | `#6B7F72` | 灰綠：中性、對照組、蔬菜（只當色塊，不當文字顏色） |
| `--muted` | `#7A6A5C` | 註腳、出處 |
| `--hi` | `#FFFFFF` | 只用在 CTA 白卡 |
| `--soft` | `rgba(59,47,39,0.08)` | 卡片底 |

淺底注意：design-system.md 預設是深底，套用時把「白色膠囊／白色徽章」改成 `--ink` 底＋`--bg` 字，光圈改用 `--r3`，CTA 白卡裡的字用 `--ink`；彩色色塊（r1～r4）上的字用白色 `--hi`。
範本：`projects/busy-diet/composition/index.html`。

## 畫面偏好

- 多用**餐盤、便當、食物份量**的圖解（蔬菜、蛋白質、澱粉、好油脂分區）。
- 生活場景：會議便當、出差、機場、聚餐應酬、帶小孩的媽媽。
- 剖面以**胃、肌肉、脂肪的能量收支**為主，語氣溫和，不畫誇張的肥胖身材。
- **不畫**：產品包裝、品牌 logo、前後對比、體重計上的公斤數、身材羞辱的畫面。
