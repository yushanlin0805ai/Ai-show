# brand.md：宇姍教練

## 配色（覆蓋 design-system.md 的 token）

> 暫定「自然、溫柔」這組（深苔綠＋奶茶杏），使用者還沒指定顏色；之後要換跟我說即可。

| Token | 色碼 | 用途 |
|---|---|---|
| `--bg` | `#22302A` | 深苔綠底色 |
| `--ink` | `#F3EFE6` | 主要文字 |
| `--r1` | `#D98B7A` | 乾燥玫瑰：提醒、常見迷思 |
| `--r2` | `#C9A66B` | 暖金：次要強調 |
| `--r3` | `#E8C9A0` | 奶茶杏：**本集主角** |
| `--r4` | `#7E9A8B` | 灰綠：中性、對照組 |
| `--muted` | `#B4BFB6` | 註腳、出處 |
| `--hi` | `#FFFFFF` | 光圈、膠囊標籤 |

做 composition 時，把上表的值寫進 `:root`，其餘照 design-system.md。

## 畫面偏好

- 多用**餐盤、便當、食物份量**的圖解（蔬菜、蛋白質、澱粉、好油脂分區）。
- 生活場景：會議便當、出差、機場、聚餐應酬、帶小孩的媽媽。
- 剖面以**胃、肌肉、脂肪的能量收支**為主，語氣溫和，不畫誇張的肥胖身材。
- **不畫**：產品包裝、品牌 logo、前後對比、體重計上的公斤數、身材羞辱的畫面。
