# 產業守則：身心靈品牌（範例）

產業：身心靈

> 從 `.claude/skills/brand-setup/references/industries.md` 的「身心靈」複製，再加上品牌自己的規定。
> 不是法律意見；正式投放廣告前請找熟悉法規的人確認。

## 1. 法規重點

- **不宣稱醫療或心理治療效果**：不說治療憂鬱、焦慮、恐慌、失眠、創傷；不暗示可以取代就醫或吃藥（醫療法）。
- **沒有心理師證照，不用「心理諮商」「心理治療」「諮商師」**描述自己的服務（心理師法）。
  → 用「陪伴」「引導」「對談」「練習」「自我覺察」。
- **不保證結果、不預測**：改運、轉運、保證成功、預測健康（公平交易法：不實廣告）。
- **不用恐懼推銷**：不做會有厄運、業障、被下咒。

## 2. 這個品牌自己的規定

1. 講到情緒和壓力，用「很多人會」「有研究發現」，不說「一定」。
2. 每支影片的練習要**安全**：不憋氣過久、不做過度換氣；說明文字加一句「如果練習中覺得頭暈不舒服，就停下來正常呼吸」。
3. 說明文字固定加一句：「長期睡不好、情緒低落，請找醫師或心理師聊聊。」
4. 呼吸、神經系統的研究數字要有出處。

## 3. 禁用詞（給 zh-beats.py 的 --extra）

```
治療|治癒|療癒創傷|心理諮商|心理治療|憂鬱症|焦慮症|恐慌症|保證|改運|轉運|業障|消災|招財|預測
```
