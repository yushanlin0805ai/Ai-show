# brand.md：身心靈品牌（範例）

## 配色（覆蓋 design-system.md 的 token）

| Token | 色碼 | 用途 |
|---|---|---|
| `--bg` | `#22302A` | 深苔綠底色 |
| `--ink` | `#F3EFE6` | 主要文字 |
| `--r1` | `#D98B7A` | 乾燥玫瑰：緊繃、壓力 |
| `--r2` | `#C9A66B` | 暖金：次要強調 |
| `--r3` | `#E8C9A0` | 奶茶杏：**本集主角** |
| `--r4` | `#7E9A8B` | 灰綠：放鬆、中性 |
| `--muted` | `#B4BFB6` | 註腳、出處 |
| `--hi` | `#FFFFFF` | 光圈、膠囊標籤 |

做 composition 時，把上表的值寫進 `:root`，其餘照 design-system.md。

## 畫面偏好

- 動作要**慢**：比預設慢 1.5 倍，多用呼吸節奏的縮放（吸 4 秒、吐 6 秒）。
- 剖面以**肺、橫膈膜、神經、肌肉緊繃與放鬆**為主；「緊繃 → 放鬆」用同一個剖面換顏色（`--r1` → `--r4`）。
- 每支影片留一段 10～20 秒的「跟著做」畫面：一個會跟著呼吸節奏變大變小的圓，搭配倒數。
- 不用宗教、靈性符號當主視覺（避免玄的感覺）。
