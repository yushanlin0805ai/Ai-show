# brand.md：熬夜族保健品品牌（範例）

## 配色（覆蓋 design-system.md 的 token）

| Token | 色碼 | 用途 |
|---|---|---|
| `--bg` | `#141B34` | 深夜藍底色 |
| `--ink` | `#F1EEF8` | 主要文字 |
| `--r1` | `#F2A65A` | 暖橘：警示、熬夜的代價 |
| `--r2` | `#E6C27A` | 燈光黃：次要強調、咖啡 |
| `--r3` | `#B9A6F2` | 薰衣草紫：**本集主角** |
| `--r4` | `#6E7BA8` | 灰藍：中性、對照組 |
| `--muted` | `#A9B0CC` | 註腳、出處 |
| `--hi` | `#FFFFFF` | 光圈、膠囊標籤 |

做 composition 時，把上表的值寫進 `:root`，其餘照 design-system.md。

## 畫面偏好

- 多用「夜晚」：剖面卡上方放 🌙／時鐘，時間推進時背景從 `#141B34` 變更深。
- 剖面以**大腦、眼睛、血液、胃**為主（跟減重品牌常用的脂肪、肌肉做出區隔）。
- 時鐘、時間軸很適合這個主題：「晚上 11 點 → 凌晨 2 點 → 早上 7 點」同一個剖面換狀態。
- 不畫產品包裝。
