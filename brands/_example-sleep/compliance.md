# 產業守則：熬夜族保健品品牌（範例）

產業：食品／保健食品

> 從 `.claude/skills/brand-setup/references/industries.md` 的「食品／保健食品」複製，再加上品牌自己的規定。
> 不是法律意見；正式投放廣告前請找熟悉法規的人確認。

## 1. 法規重點（食品安全衛生管理法第 28 條＋認定準則）

- **不能宣稱醫療效能**：預防、改善、減輕、診斷或治療疾病或症狀。
  → 不說「改善失眠」「治療睡眠障礙」「消除疲勞」。
- **不能說改變身體器官、組織、生理功能**：補腦、增強記憶力、增強抵抗力、改善體質、排毒、抗老。
- **沒有證據不說**；不引用公文字號；品名不用「健康」二字（除非是有小綠人的健康食品）。
- 判斷看**整體**：字幕沒寫，口播講了也算；畫面放產品＋「一覺到天亮」的字也算。

## 2. 這個品牌自己的規定

1. **影片講知識，不講產品**。產品不出現在影片中段，只在 CTA 之後的諮詢裡依需求推薦。
2. 不給安眠藥、褪黑激素的用量建議；有長期失眠困擾 → 說明文字提醒「請找醫師」。
3. 不羞辱熬夜的人，語氣是「熬夜也要熬得聰明」。
4. 咖啡因、睡眠相關的數字（半衰期、建議攝取量）都要有出處（例：衛福部、食藥署、FDA、EFSA 的公開資料）。

## 3. 禁用詞（給 zh-beats.py 的 --extra）

```
失眠|助眠|安眠|一覺到天亮|秒睡|治療|改善症狀|消除疲勞|補腦|增強記憶|增強抵抗力|改善體質|排毒|抗老|防老
```
