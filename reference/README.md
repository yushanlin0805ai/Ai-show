# 風格參考

- `aspartame-2b.html`：「2B 是什麼意思？」IARC 致癌分級階梯動畫（約 17 秒，含內嵌音檔）。用瀏覽器打開就能播放。
- 從這個檔案萃取出的設計規範在 `.claude/skills/broll-video/references/design-system.md`。

新增參考檔時，放在這個資料夾，並在 design-system.md 註明哪些規則來自哪個檔。
- `cross-section-fat.html`：剖面動畫範例（皮膚 → 脂肪層，脂肪細胞變小），12 秒；網址加 `?t=6` 可停在指定秒數
- `cross-section-parts.html`：剖面零件庫（皮膚分層、微血管、肌肉與粒線體、肺泡、小腸絨毛、胃），剖面模式從這裡複製零件
- `cross-section-3d-block.html`：立體切塊剖面範例（2.5D：轉角度、掀開上層、脂肪細胞變小），12 秒
