# 內容守則（Compliance）

**每次製作都要遵守。** 在步驟 1（讀逐字稿時）、步驟 2（寫分鏡時）、步驟 6（交付前）各檢查一次。

## 1. 四條守則

1. **先讀品牌的產業守則**
   `brands/<品牌>/compliance.md` 有這個產業特有的禁用詞與規定（例：保健食品、身心靈、減重）。和本檔衝突時，**以比較嚴格的為準**。
   測驗、星座、塔羅、能量這類「趣味入口」只能當 CTA 的開始，不能宣稱它能診斷身體、心理狀況或預測結果。

2. **不用療效或保證用語**
   畫面文字、字幕、標題都不能出現下列用語（含變化寫法）：
   - 治療、治癒、根治、療效、藥效
   - 保證瘦、保證有效、一定瘦、必瘦、絕對、100% 有效
   - 神奇、奇蹟、排毒
   - 預防癌症、抗癌、降血糖、降血壓（作為產品或方法的功效時）
   - 產業特有的詞（例：快速瘦、一覺到天亮、療癒創傷）列在 `brands/<品牌>/compliance.md`

   如果**口播本身**用了這些詞，字幕照實呈現會違規 → 停下來告訴使用者，請他決定是否重錄或修改字幕，**不要自己改**。

3. **數字與研究要有出處**
   畫面上出現的每個數字、分級、研究結論，都要列在 `projects/<影片名稱>/storyboard/sources.md`：
   - 說法（畫面上怎麼寫）
   - 出處（機構／期刊、年份、標題、網址）
   - 狀態：`待使用者確認` → 使用者確認後改成 `已確認`
   - 交付時提醒使用者：**發布前請逐條確認 sources.md**。
   - 沒有出處的數字不上畫面（留在字幕即可，並標出來問使用者）。

4. **逐字稿看起來不精確 → 標出來問，不要自己改**
   常見情況：
   - 數字或單位可能錯（例：每日攝取量算法、罐數）
   - 把「分類等級」講成「風險大小」這類容易誤解的說法
   - 研究結論講得太絕對（「研究證明」vs「有研究發現」）
   - 錯字、專有名詞不一致
   處理方式：在分鏡表後面的「逐字稿疑點」列出：句號、原文、疑點、建議（只是建議），等使用者回覆。

## 2. 檢查方式

```bash
# 掃描禁用詞（逐字稿、分鏡）
grep -nE "治療|治癒|根治|療效|藥效|保證|絕對|100%|排毒|神奇|奇蹟|抗癌" <檔案>
# 再加上 brands/<品牌>/compliance.md 列的產業禁用詞
# 畫面 HTML：先去掉 <style>、<script> 與標籤，只掃畫面上的文字（避免 CSS 的 100% 誤判）
python3 -c "import re,sys;t=open(sys.argv[1],encoding='utf-8').read();t=re.sub(r'(?s)<(style|script)[^>]*>.*?</\1>','',t);print(re.sub(r'<[^>]+>','\n',t))" <index.html> \
  | grep -nE "治療|治癒|根治|療效|藥效|保證|絕對|100%|排毒|神奇|奇蹟|抗癌"
```

有找到就列給使用者看，說明是哪個檔案、哪一句。

## 3. 其他注意

- 不使用羞辱或製造焦慮的畫面（身材對比、黑眼圈特寫嘲笑等）。
- 知識型內容的語氣是「降低焦慮、提供判斷依據」，不製造恐慌。
- 引用 WHO、IARC、衛福部等機構時，名稱寫全名或通用簡稱，不要張冠李戴（例：IARC 負責致癌分級；每日可接受攝取量 ADI 是 JECFA 訂的）。
