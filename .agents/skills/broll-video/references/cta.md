# 結尾 CTA

## 1. 變數

CTA 文字做成變數，放在每個專案的 `projects/<影片名稱>/project.json`。內容從 `brands/<品牌>/cta.json` 複製過來（沒有的話請使用者先跑 brand-setup）：

```json
{
  "cta": {
    "question": "想知道自己的卡點在哪裡嗎？",
    "action": "留言「測驗」，領取免費測驗！",
    "keyword": "測驗"
  }
}
```

| 變數 | 預設值 | 用途 |
|---|---|---|
| `cta.question` | （品牌的提問句） | CTA 第一句（提問） |
| `cta.action` | （留言＋領取什麼） | CTA 第二句（行動） |
| `cta.keyword` | （留言關鍵字） | 留言關鍵字，畫面上放大強調 |

要換 CTA 時只改 `project.json`，不要改畫面 HTML。

## 2. 畫面版面（CTA 卡）

- 背景 `--bg`，全螢幕（模式 B 也是全螢幕，講者在 CTA 前一句結束）。
- 上方（y≈500）：`cta.question`，8cqw、900、`--ink`。
- 中間：白色圓角大卡（`--hi` 底、`--bg` 字），裡面寫「留言」＋關鍵字膠囊；關鍵字用 `--r3` 底、12cqw、900。旁邊放 💬 emoji。
- 下方：`cta.action` 的後半段（領取…）用 5cqw、700。
- 動畫：提問淡入 → 0.4s 後白卡彈入（彈跳曲線）→ 關鍵字膠囊 1.1s 呼吸循環（同參考檔光圈）。
- 字幕：「我是…老師」照常顯示；`cta.question` 大字出現後隱藏字幕（`#captions` 加 `data-hide-from="<秒數>"`），因為 CTA 大字就是口播內容，不重複顯示。
- 停留：口播結束後再多停 1.0 秒，總長至少 3 秒。

## 3. 守則

- 測驗、星座這類趣味入口只是開始（見 `compliance.md` 第 1 條），CTA 畫面不得宣稱它能診斷或保證結果。
- 測驗名稱以 `cta.action` 為準。若口播講的名稱和變數不一樣，標出來問使用者。
