# 剖面動畫（Cross-section）

> 參考：IG @life_hack_ai_ 的「斷面解說動畫」（日文：断面解説動画），例如講毛囊蟲的那支。
> 這種影片是 Claude 用程式碼一格一格畫出來的：作者在自己的技能 `danmen-kaisetsu-douga` 裡寫好「規則資料夾」（腳本範本、畫法、字幕），
> 流程是 主題 → 腳本（前 3 秒的鉤子）→ 配音（ElevenLabs 或本人）→ 逐字時間點 → 用程式碼畫每一格 → Claude 自己抽格檢查 → 輸出影片＋說明文字。
> 這套 repo 的 broll-video 已經是同樣的流程；本文件補上的是**剖面的畫法**。
>
> 範例：`reference/cross-section-fat.html`（皮膚到脂肪層的剖面，脂肪細胞變小）。新的剖面畫面從它複製再改。

## 1. 什麼時候用剖面

| 適合 | 例子 |
|---|---|
| 「裡面發生什麼事」：看不到的身體構造 | 皮膚分層、脂肪細胞、胃、腸道、血管、肌肉纖維 |
| 「東西跑去哪裡」：吃進去、吸收、儲存、代謝 | 糖變成肝醣、脂肪細胞變大變小 |
| 「白天／晚上」「之前／之後」的同一個位置 | 同一個剖面換光線或換狀態 |

不適合：數字比較、分級（用 design-system.md 的色條）；純概念（用卡片）。
分鏡表裡畫面類型仍然寫「全」，畫面描述開頭寫「剖面：」。

## 1-1. 剖面模式（整支影片以剖面為主）

使用者說「剖面動畫」「剖面為主」「多一點剖面」，或 project.json 有 `"visual": "cross-section"` 時，改用這套規則。
**預設的設計系統（圖示卡、色條）在剖面模式裡只是配角。**

1. **比例**：除了開場標題和結尾 CTA，**至少 70% 的畫面時間是剖面**。分鏡表的規則自檢要算出這個比例，不到就重排。
2. **數字放進剖面裡**：「84% 變成二氧化碳」不是另做一張色條卡，而是在肺泡剖面上，讓 CO₂ 粒子離開時旁邊跳出「84%」標籤。只有剖面真的畫不出來的概念（年份、論文名）才用小卡，而且小卡疊在變暗的剖面上，不切到純色背景。
3. **一條路線走到底**：把主題想成「跟著一個東西在身體裡移動」（例：一顆脂肪分子 → 血管 → 肌肉 → 肺）。畫面之間用**鏡頭移動**（平移、推近、拉遠）接起來，不用淡出淡入切換。
4. **一支影片 3～5 個「場景」**，每個場景是一張剖面（例：皮下脂肪層、微血管、肌肉纖維與粒線體、肺泡），每個場景停留 8～15 秒，裡面靠標籤、粒子移動、鏡頭推近來換「畫面」。這樣「同類型不可連續超過兩次」的規則改成：**同一個場景裡，每 3～4 秒要有一個新的動作或標籤**。
5. **主角要看得到**：被追蹤的那個東西（脂肪分子、糖、氧氣）用 `--r3` 加白色光圈，從頭到尾同一個造型，觀眾才跟得上。
6. **零件從 `reference/cross-section-parts.html` 拿**（皮膚分層、脂肪細胞、微血管與紅血球、肌肉纖維與粒線體、肺泡、小腸絨毛）。沒有的零件照第 3 節的配色新畫，畫好後加回零件庫。
7. **分鏡表**：類型欄寫「剖面:場景名」，畫面描述寫清楚「鏡頭從哪裡移到哪裡」「哪個字出現哪個標籤」「粒子從哪裡流到哪裡」。

腳本也要配合（reel-pipeline 步驟 ① 會處理）：每一句都要能指到身體裡的一個位置。像「關鍵是用掉多少熱量」這種抽象句，改成「肌肉裡的粒線體，把脂肪拆開來用掉」。

## 1-2. 立體切塊（2.5D，選用）

想要比平面剖面更有立體感時用：把一塊組織切成長方體，正面和側面看得到分層，頂面看得到表面（毛孔、汗毛），
可以慢慢轉角度、把上面幾層「掀開」露出下一層的頂面。範例：`reference/cross-section-3d-block.html`（12 秒）。

- 不用 3D 引擎：每一層是一個長方體，用透視投影算出每個面的位置，再把平面剖面圖用 SVG `matrix()` 貼上去。渲染速度和平面剖面一樣。
- 平面剖面的零件（分層顏色、脂肪細胞、肌肉條紋、血管）可以直接貼到立體面上。
- 一支影片用 1～2 次就好（開場建立「我們在身體哪裡」、或要掀開看下一層的時候），其餘仍用平面剖面，比較好讀。
- 轉角度幅度 ±25° 以內、速度慢（整段 8～10 秒轉完），太快會暈。
- 掀開的那幾層往上＋往後退，不要擋到要看的那一層；也不要跑進畫面上方 200px 的 IG 介面區。

## 2. 版面

```
y 200–360    （模式 A）畫面標題，可省略
y 380–1300   剖面卡：圓角 3cqw 的矩形，寬 88cqw，置中；卡片裡才是剖面
y 1300–1340  註腳／出處
y 1375–1580  字幕（照 design-system.md）
```

- **剖面一定裝在卡片裡**，不要滿版。卡片＝「透過一個窗戶看進身體裡」，四周留 `--bg`。
- 剖面是**正側面**的切面，地層一樣由上往下水平分層，**不用透視**。
- 一張卡片只講一個構造。換構造就換卡片（淡出淡入），不要在卡片裡一直加東西。

## 3. 組織配色（只在剖面卡裡用）

| 層 | 色碼 | 畫法 |
|---|---|---|
| 空氣／皮膚外 | `#1E2C3A`（比 `--bg` 亮一點） | 純色 |
| 表皮 | `#E8A79A` | 薄層，上緣微微起伏 |
| 真皮 | `#7A3536` → `#5E2729` | 上下兩色漸層；加 3～4 條細的半透明橫線（`#000` 12%）表示纖維層次 |
| 皮下脂肪細胞 | `#F2C76B`，邊框 `#C99A3E` | 圓形或圓角六角形，蜂巢排列；間隙填 `#E9B24F` 40% |
| 肌肉 | `#9E4444`，條紋 `#B65A5A` | 斜向細條紋 |
| 血管 | `#C8423B`（動脈）、`#5B6FB3`（靜脈） | 圓管，一條就好 |
| 皮脂腺／分泌物 | `#E9B24F` | 小顆粒一串 |
| 主角（本集重點） | 照 design-system.md：`--r3` 外加白色光圈 | 一個畫面只有一個主角 |

規則：
- 組織顏色是**寫實的暖色系**，畫面其他東西（字幕、標籤、背景）維持系列的深藍＋米白，主角才跳得出來。
- 不畫血淋淋的細節：沒有傷口、沒有液體噴濺。剖面是乾淨的教科書插圖。
- 不畫身材羞辱的畫面（胖瘦對比、捏肚子）。要講「變胖／變瘦」，就畫細胞變大變小。

## 4. 標籤（引線標註）

- 小字 3.3cqw、700、`--ink`，放在剖面卡內側左右邊緣，用 0.25cqw 的細線（`--ink` 70%）連到構造，線的末端一個 0.8cqw 圓點。
- 標籤**跟著口播出現**：講到那個名詞的那一刻（`timing/words.json`）才畫線＋淡入字。線用 `stroke-dashoffset` 0.4 秒畫出來。
- 一張卡片最多 4 個標籤；舊標籤在新標籤出現時降到 50% 不透明度。

## 5. 動作（GSAP）

| 動作 | 做法 | 用在 |
|---|---|---|
| 剖面揭開 | 卡片先出現 → 各層由上而下 0.15 秒間隔 `fadeUp` | 第一次出現 |
| 鏡頭推近 | 對卡片內的 `<g>` 做 `scale`＋`transform-origin`（1.0 → 1.8，1.2 秒，`power2.inOut`）；卡片外框不動 | 從整體看到局部 |
| 狀態變化 | 同一個構造改 `scale`／顏色（例：脂肪細胞 1 → 0.62，2 秒，`sine.inOut`），**數量不變** | 變大／變小、發炎／正常 |
| 時間切換 | 卡片頂端放 ☀️／🌙，背景 `#1E2C3A` ↔ `#101B2D` 1 秒過渡 | 白天／晚上 |
| 移動的小東西 | 沿 `motionPath` 或直線，每段 ≥ 1 秒，最多 3 個同時動 | 糖、脂肪酸、氧氣進出 |
| 持續感 | 細胞 1.5% 的呼吸縮放、粒子 2px 漂浮（有限次數） | 畫面停留超過 3 秒時，避免看起來像當掉 |

## 6. 和參考影片不一樣的地方（刻意的）

- 參考影片的字幕放在**畫面上方**、已經念過的字變灰。本系統字幕維持在**下方字幕區**（design-system.md），因為上方會被 IG 介面蓋到。
- 參考影片結尾是「傳給一個人」的分享 CTA。本系統結尾固定用 cta.md 的留言關鍵字 CTA。
- 參考影片是 canvas 逐格畫；本系統用 Hyperframes（HTML＋SVG＋GSAP），一樣是程式碼畫的，但可以直接沿用現有的字幕、CTA、檢查流程。

## 7. 出處

剖面講的每一個構造事實（例：「成人脂肪細胞數量大致固定，變瘦時是細胞變小」）都要進 `sources.md`，和數字一樣處理。
