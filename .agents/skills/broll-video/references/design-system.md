# 設計規範（Design System）

> 來源：`reference/aspartame-2b.html`（「2B 是什麼意思？」IARC 致癌分級階梯動畫，約 17 秒）。
> 本文件把它的視覺語言拆成可重複使用的規則。所有新畫面都要遵守；要破例請先在分鏡表註明理由。

---

## 1. 畫布與單位

| 項目 | 規格 |
|---|---|
| 尺寸 | 1080 × 1920（9:16），30fps |
| 單位 | 參考檔用 `cqw`（畫面寬度的 1%）。**1cqw = 10.8px**。本規範同時列出 cqw 與 1080 寬時的 px |
| 背景 | 純色深藍 `--bg`，不用漸層、不用照片底 |
| 左右安全邊 | 6cqw（65px）給圖形；7cqw（76px）給文字 |

IG／Reels 介面會蓋住畫面上下與右側，所以另外規定**平台安全區**（參考檔沒有，這是補充）：

| 區域 | 範圍（px） | 用途 |
|---|---|---|
| 上方 UI 區 | y 0–200 | 不放重要資訊（帳號名、音樂列會蓋到） |
| 主視覺區 | y 200–1340 | 標題、圖表、物件（註腳放在這區最下方） |
| 字幕區 | y 1375–1580 | 只放字幕 |
| 下方 UI 區 | y 1580–1920 | 留白；IG 說明文字、愛心、留言鈕會蓋到 |
| 右側按鈕 | x 940–1080、y 1000–1700 | 不放文字 |

## 2. 配色

| Token | 色碼 | 用途 |
|---|---|---|
| `--bg` | `#172A3A` | 畫面底色（深藍灰）；也用作色塊上的文字顏色 |
| `--ink` | `#F4F1E8` | 主要文字（米白，不用純白，比較柔和） |
| `--r1` | `#E76F51` | 珊瑚紅：最高等級／最嚴重／警示 |
| `--r2` | `#F4A261` | 橘：次高等級 |
| `--r3` | `#E9C46A` | 芥末黃：**本集主角**、要被注意的那一格 |
| `--r4` | `#6C8EA4` | 灰藍：最低／中性／對照組 |
| `--muted` | `#B9C7D1` | 註腳、出處、次要說明 |
| `--hi` | `#FFFFFF` | 只用在「強調」：外框光圈、問號徽章、膠囊標籤 |
| 頁面外框 | `#0E1A24` | 只在 HTML 預覽時舞台外的底色，影片中不會出現 |

用色原則：
- **r1→r4 是一組「由重到輕」的順序色**，凡是分級、排名、風險高低，都照這個順序上色。
- 色塊上的文字一律用 `--bg`（深色字壓在亮色塊），深底上的文字用 `--ink`。
- 純白 `#fff` 是「請看這裡」的訊號，一個畫面同時最多出現一處白色強調。
- 不新增顏色。需要第五種顏色時，用現有顏色調整不透明度（例如 `--ink` 40%）。

## 3. 字型與字級

- 字型：**Noto Sans TC**（放在 repo 的 `fonts/`，渲染時用 `@font-face` 載入本機檔案，不依賴網路或系統字型）。
  備援順序：`"Noto Sans TC","PingFang TC","Microsoft JhengHei",system-ui,sans-serif`。
- repo 內附三種字重：400（Regular）、700（Bold）、900（Black）。參考檔用的 600 會顯示為 Bold、800 會顯示為 Black；新畫面直接寫 400／700／900。

| 角色 | 字級 | px（1080 寬） | 字重 | 行高／字距 | 參考檔元素 |
|---|---|---|---|---|---|
| 畫面標題 | 10cqw | 108 | 800 | 字距 .02em | `#ttl` |
| 大數字／分級名 | 7–8.5cqw | 76–92 | 800 | 行高 1.1 | `.row b`、`.chip span` |
| 字幕 | 6.4cqw | 69 | 700 | 行高 1.35 | `#cap p` |
| 膠囊標籤 | 3.8cqw | 41 | 800 | — | `.up` |
| 分級說明 | 3.6cqw | 39 | 600 | — | `.row i` |
| 註腳／出處 | 3.4cqw | 37 | 700 | — | `#fn`；畫面上至少停留 2.5 秒 |
| 卡片標籤 | 3.3cqw | 36 | 700 | — | `.chip` |

字級比例大約是 **標題 : 字幕 : 註腳 ≈ 3 : 2 : 1**。最小字不低於 3.3cqw（36px），手機上才看得清楚。

## 4. 物件造型

全部是「圓角矩形＋純色塊＋emoji」的扁平風格，沒有陰影、沒有描邊（白色強調框除外）、沒有漸層。

| 元件 | 造型 | 尺寸（cqw） | 用法 |
|---|---|---|---|
| **色條 Row** | 圓角 3cqw 的橫向色塊，左側放「大字＋小字說明」，右側留空位放卡片 | 高 25、寬滿版（左右 6）、間距 3 | 分級、階梯、排名、比較表 |
| **卡片 Chip** | 圓角 2.5cqw，`--bg` 底、`--ink` 字；上方 emoji（8.5cqw），下方標籤 | 17 × 19 | 代表一個「東西」：食物、飲料、行為 |
| **光圈 Ring** | 0.9cqw 白色外框，比目標大 1.6cqw，呼吸放大縮小 | — | 「就是這個！」強調本集主角 |
| **問號徽章** | 8cqw 白色圓形，深色粗體「?」 | 8 × 8 | 釘在目標右上角，表示「有疑問／待解釋」 |
| **膠囊標籤** | 白底深字、全圓角（5cqw） | padding 1.2 × 3.4 | 箭頭說明，如「▲ 更高等級」 |
| **註腳** | `--muted` 色小字，置中 | 底部 5cqw | 一句話結論或出處簡寫 |

新物件的延伸規則：
- 數字比較用「長條」：同樣圓角色條，長度代表數值，數值寫在條內（深色字）。
- 清單用「色條堆疊」：每項一條，依序滑入，最多 4 項。
- 物件用 emoji 表示（🥤🍷🥩📱🥒⚖️💧），不用圖庫照片或寫實插圖。同一支影片 emoji 風格要一致。
- 人物、身體部位用 emoji 或簡單幾何形，不畫寫實身體（避免身材焦慮聯想）。

## 5. 動畫節奏

| 動作 | 規格 | 參考檔 |
|---|---|---|
| 一般進場 | 淡入 0.35s ＋ 位移 0.45s（ease） | `[data-t]` |
| 標題進場 | 由下往上 2cqw ＋ 淡入 | `#ttl` |
| 色條進場 | 由左往右 5cqw ＋ 淡入，**每條間隔 0.5s** | `.row` |
| 卡片進場 | 從上方 8cqw、縮放 0.6 彈入，彈跳曲線 `cubic-bezier(.3,1.6,.5,1)` 0.45s | `.chip` |
| 強調光圈 | 1.1s 呼吸循環（ease-in-out，無限） | `.ring` |
| 退場 | 只有字幕會退場（淡出）；圖形元素進場後留到這個畫面結束 | `data-e` |

節奏原則：
1. **畫面跟著嘴巴走**：每個元素的出現時間對齊口播中「說到那個詞」的時間點（例：說「醃漬蔬菜」那一刻，醃漬蔬菜卡片才彈進來）。
2. **先架構、後內容**：先出標題與框架（色條），再一個一個放進內容（卡片），最後才出強調（光圈、標籤）。
3. 一次只動一件事，元素間至少隔 0.3s。
4. 圖形「累積」而不是「替換」：同一個畫面內越講越完整，結尾停在一張可截圖的完整資訊圖。
5. 不用旋轉、翻轉、閃爍、震動等花俏效果。

製作時（Hyperframes）用 GSAP timeline 實作上面的時間，所有動畫必須可「跳到任一秒」重播（seekable），不能用 `setTimeout` 或 CSS transition 自己跑。

## 6. 字幕樣式

| 項目 | 規格 |
|---|---|
| 位置 | 左右各 76px（7cqw），y 1375–1580（高 205px）的區塊內，**底部對齊**、置中。參考檔的字幕貼近底部（底部 13cqw），那是網頁播放器版面；Reels 底部會被介面蓋住，所以上移到字幕區 |
| 字 | 6.4cqw（69px）、700、`--ink`、行高 1.35 |
| 背景 | 無底框、無描邊（底色夠深）。模式 B 疊在實拍上時才加：文字描邊 0.12em `#172A3A` ＋ 陰影 |
| 斷句 | **一則字幕只用一行，≤ 13 字寬**（中文 1、英數 0.5；字幕框 928px ÷ 69px）。先在逗號處拆，太長再在「詞與詞之間」拆（用 Node 內建的 Intl.Segmenter 斷詞），不拆開「」裡的詞與專有名詞、不切在數字中間。只有一兩個字的片段（如「因此，」）併到下一則，該則若超過一行會自動縮字。句尾「？」「！」保留，逗號和句號拿掉 |
| 時間 | 每則字幕從那句話開始講時出現，到下一則出現時消失，中間不留空白閃爍 |
| 用字 | 以使用者的逐字稿為準，不用辨識結果的錯字 |

## 7. 兩種模式的版面差異

**模式 A（只有錄音，全動畫）**
- 整個畫面都是動畫；字幕永遠在字幕區。
- **第 0 格就要有標題**（社群平台用第一格當縮圖），不要從全空的畫面淡入。
- CTA 畫面出現大字後隱藏字幕（`#captions` 的 `data-hide-from`），避免同一句話出現兩次。
- 結尾 CTA 卡依 `cta.md` 版面。

**模式 B（實拍口播＋B-roll）**
- **全螢幕動畫**：直接切成動畫畫面（不透明 `--bg` 底），講者暫時不出現。
- **小物件疊加**：透明背景（`background: transparent`，輸出 WebM／MOV 含透明通道），物件只能放在**臉部安全區以外**：
  - 預設假設講者臉在 x 216–864、y 300–1000（畫面中間偏上）。製作前用抽格畫面確認實際位置，記在分鏡表。
  - 小物件放在下半部 y 1000–1240（字幕區上方）或臉部左右兩側的空位，寬度不超過 400px。
  - 小物件不加整塊底色；需要底時用 `--bg` 85% 不透明的圓角卡。
- 字幕在實拍上要加描邊（見上表）。

## 8. 範例：參考檔的時間表（17 秒）

| 秒 | 元素 | 對應口播 |
|---|---|---|
| 0.15 | 標題「2B 是什麼意思？」 | 那 2B 到底是什麼意思？ |
| 1.8 / 2.3 / 2.8 / 3.3 | 四條分級色條依序滑入（1→2A→2B→3） | 簡單來說… |
| 3.0 | 🥤阿斯巴甜 卡片放入 2B | — |
| 3.8 | 白色光圈＋問號 圈住 2B | 發現了一些疑慮 |
| 7.4 | 🥒醃漬蔬菜 放入 2B | 其實像是醃漬蔬菜 |
| 9.6 | 📱手機射頻 放入 2B | 手機通訊使用的射頻電磁場 |
| 12.9 | 🥩紅肉 放入 2A | 反而紅肉 |
| 13.7 | 🍷酒精 放入 1 | 或者酒精 |
| 15.1 | 膠囊「▲ 更高等級」 | 還在更高的等級 |
| 15.6 | 註腳「分類看的是證據強度，不是風險大小」 | — |

這是本系統「好畫面」的標準：**一個畫面講清楚一個概念，元素隨口播逐一出現，結尾停在一張完整的資訊圖。**

## 9. 檢查清單

- [ ] 只用第 2 節的顏色
- [ ] 字型是 Noto Sans TC（截圖確認不是方框或其他字型）
- [ ] 文字都在安全區內，最小字 ≥ 36px
- [ ] 每個元素出現時間對齊口播關鍵字（誤差 ≤ 0.2 秒）
- [ ] 一個畫面最多一處白色強調
- [ ] 模式 B：小物件沒有蓋到臉
