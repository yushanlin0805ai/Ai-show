# 產業守則範本（台灣）

> brand-setup 依使用者的產業，把對應段落複製到 `brands/<品牌>/compliance.md`。
> 這是整理常見規定，**不是法律意見**；法規會修改，正式投放廣告、放客人見證前請找熟悉法規的人確認。
> 最後整理：2026-11。

---

## 食品／保健食品（含膠囊、粉包、飲品）

**法源：** 食品安全衛生管理法第 28 條；「食品及相關產品標示宣傳廣告涉及不實誇張易生誤解或醫療效能認定準則」（衛福部）。
IG 貼文、限動、影片、直播都算「宣傳或廣告」；判斷看的是**整體表現**：字幕、口播、畫面、圖示、音樂一起看。

**不能說：**
1. **醫療效能**：預防、改善、減輕、診斷或治療任何疾病或症狀。
   例：改善失眠、治療焦慮、降血壓、降血糖、消除疲勞症狀、緩解頭痛。
2. **改變身體器官、組織、生理功能或外觀**（被認定為誇張、易生誤解）。
   例：補腦、增強記憶力、改善體質、排毒、增強抵抗力、防止老化、減肥、塑身、美白。
3. **沒有證據或證據不足**的效果；與事實不符的說法。
4. 引用公文字號（「衛署食字第…號」）讓人以為政府背書。
5. 品名有「健康」二字，但不是取得許可的健康食品（有小綠人標章的才算）。

**可以說：**
- 認定準則「附件一」列的通常可使用詞句（例：幫助消化；完整清單以衛福部最新公告為準，寫腳本前請 AI 查最新版）。
- 「附件二」列的營養素生理功能（例：某維生素「有助於維持正常的生理機能」這類，**要照公告原文**）。
- **講知識，不講產品效果**：影片講「熬夜時身體發生什麼事」是衛教；講「吃了我們的產品就不怕熬夜」就是廣告宣稱。兩者要分開，產品只出現在 CTA 的領取內容，不在影片中段推銷。

**禁用詞（給 zh-beats.py 的 --extra）：**
`失眠|助眠|安眠|一覺到天亮|秒睡|治療|改善症狀|消除疲勞|補腦|增強記憶|增強抵抗力|改善體質|排毒|抗老|防老|減肥|瘦身|塑身|燃脂`

## 身心靈（冥想、能量、塔羅、占星、靈性成長、身心調理）

**常見相關法規：** 醫療法（非醫療機構不得做醫療廣告）；心理師法（心理諮商、心理治療是心理師的業務，沒有證照不能以此名義執業）；公平交易法（不實廣告）。

**不能說：**
1. **醫療或心理治療效果**：治療憂鬱、焦慮、恐慌、失眠、創傷、PTSD、成癮；取代就醫或吃藥。
2. 沒有心理師證照時，用「心理諮商」「心理治療」「諮商師」描述自己的服務。
   → 改用「陪伴」「引導」「對談」「身心調理」「自我覺察」。
3. **保證結果或預測**：保證改運、一定會成功、預測健康、招財保證、轉運。
4. 用恐懼推銷：不做會有厄運、業障纏身、別人害你。
5. 星座、塔羅、能量、靈數**只能當「認識自己的有趣角度」**，不能說它能診斷身體或心理狀況。

**可以說：**
- 自我覺察、放鬆練習、呼吸練習的**體驗**（「很多人覺得比較放鬆」，不是「治好焦慮」）。
- 有研究支持的一般知識（例：規律呼吸練習與放鬆反應的研究），一樣要出處。
- 提醒：「如果你長期睡不好、情緒低落，請找醫師或心理師。」放在說明文字裡是加分。

**禁用詞（給 zh-beats.py 的 --extra）：**
`治療|治癒|療癒創傷|心理諮商|心理治療|憂鬱症|焦慮症|恐慌症|保證|改運|轉運|業障|消災|招財|預測`

## 減重／體態管理

**法源：** 食品安全衛生管理法第 28 條（若有食品）；醫療法（若涉及醫療行為）；公平交易法。

**不能說：** 快速瘦、X 天瘦 X 公斤、躺著瘦、不用運動也能瘦、燃脂神器、保證瘦、排毒、局部瘦；客人前後對比照、腰圍公斤數見證；身材羞辱的畫面。
**可以說：** 講自己做了什麼（陪伴、調整飲食習慣），不講客人身體變了多少；體組成、熱量、蛋白質等知識（附出處）。

**禁用詞：** `快速瘦|一定瘦|必瘦|躺著瘦|燃脂|神器|排毒|瘦身|局部瘦|保證`

---

## 一般知識型（理財、教育、職涯、親子……）

**不能說：** 保證獲利、保證收入、穩賺、一定考上；用自己的收入暗示觀眾也能賺到；未經同意使用他人照片或姓名。
**收入、成果數字：** 只能講成「我自己的經歷」，後面不接「你也可以」。
**禁用詞：** `保證|穩賺|躺著賺|一定|零風險|翻倍`
